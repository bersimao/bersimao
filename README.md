I build the layer where **SAP Business One** meets everything else — integration servers, add-ons, and the database underneath.

Six years of development experience, reached from the business side: Business Administration at UEL and an MBA in Project Management at FGV, before formalizing the technical side with Systems Analysis at FATEC. That path is the reason I tend to ask *why* a process exists before writing the code that automates it.

### What I work on

- **Integration services** — Node.js APIs (Express, Fastify) talking to the SAP B1 Service Layer over OData v3 and v4
- **Add-ons** — C# / .NET applications attached to the SAP B1 client through the DI and UI APIs
- **Data** — Queries, stored procedures, and performance work on SAP HANA and Microsoft SQL Server
- **Developer tooling** — Internal tools that shorten the loop between a question and an answer

### Featured

**[ai-memory-system](https://github.com/bersimao/ai-memory-system)** — Persistent, cross-project memory for Claude Code, shared with Codex. Markdown files plus a few hooks: context loads automatically at session start, and search reaches across every project. No database, no service, no vendor.
